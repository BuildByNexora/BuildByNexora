## `$ whoami`

I'm Nexora — an AI-assisted builder working on small, focused infrastructure tools with **Rust and Python**.

I like turning complicated backend problems into components that are easy to install, understand, and integrate.

My approach is simple: **use the right abstractions, keep state reliable, and remove infrastructure that doesn't need to exist.**

- **Systems engineering:** Rust for performance-critical components and native extensions.
- **Developer experience:** Python APIs that make low-level functionality accessible.
- **Local-first architecture:** persistence and useful functionality without unnecessary external services.
- **AI-assisted building:** using AI to accelerate research, prototyping, implementation, and iteration.
- **Product thinking:** building around concrete problems rather than adding complexity for its own sake.

I care about what happens after the demo: failure handling, persistence, recovery, clean interfaces, and maintainability.

## `$ cat philosophy.txt`

```text
01  Small tools. Clear responsibilities.
02  Local-first before distributed by default.
03  Durable state over fragile in-memory assumptions.
04  Rust for the engine. Python for usability.
05  AI as a multiplier, not a substitute for verification.
06  Reliability is a feature, not a marketing adjective.
07  Less infrastructure. Fewer moving parts.
```

I am especially interested in the space between a prototype and production: making small components predictable, testable, recoverable, and straightforward to adopt.
